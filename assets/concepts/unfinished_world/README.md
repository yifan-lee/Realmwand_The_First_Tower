# 未完成之界：首批视觉概念素材

本目录保存“未完成之界”的首批 AI 生成视觉概念。画面使用粗黑线、
纯色色块和基础几何图形，使玩家、敌人、装备、物品与地形共享同一种
符号语言。

## 色彩规则

- ATK：红色 `#F04444`
- DEF：黄色 `#F2C94C`
- SPD：蓝色 `#2F9BFF`
- 综合属性：红、黄、蓝等量组合
- 玩家识别色：青蓝色 `#2F9BFF`
- HP：洋红 / 珊瑚色心形
- MP：紫色 / 青色水滴

## 目录

- `source/`：保留绿色背景的原始生成图，便于重新抠图。
- `transparent/`：已经移除绿色背景的完整设计表。
- `split_original/`：不缩放主体、使用透明留白补成正方形的 RGBA PNG。
- `split/`：保持同表相对大小并统一为 `256×256` 的正方形 RGBA PNG。

`split/` 与 `split_original/` 目前各包含 164 张图片：

- `player/`：8 个玩家姿态。
- `monsters/`：ATK、DEF、SPD、综合型各 4 个等级。
- `equipment/wearable/`：首版头、胸、腿、脚、手装备。
- `equipment/weapons/`：首版单手、双手、盾牌、副手装备。
- `equipment/wearable_v2/`：按属性重新设计的五部位装备，推荐使用。
- `equipment/weapons_v2/`：扩展后的七类武器，推荐使用。
- `items/`：HP、MP 与四种属性兑换物各 4 个等级。
- `interactables/`：四种属性对应的 NPC、雕像和兑换终端。
- `tiles/`：地面、墙壁、门、楼梯、传送门、机关与单向洞口。

## 生成提示词摘要

所有设计表均以 `stylized-concept` 为用途，通过内置 ImageGen 生成。
共同提示要求为：

- 未完成抽象世界中的 2D 俯视 RPG 素材。
- 极简扁平矢量感、统一粗黑线、纯色色块和几何轮廓。
- 固定网格排列、主体互不重叠、无文字、无阴影、无渐变、无水印。
- 使用纯绿色背景生成，再通过本地 chroma-key 工具转换为透明 PNG。
- 玩家采用火柴人、胸口蓝色碎片与断裂魔杖。
- 等级提升通过体量、分段、核心与轮廓复杂度表达。
- 新版穿戴装备严格使用其所增加属性的对应颜色。
- 新版武器固定为单手剑、双手剑、匕首、盾牌、法杖、单手刀和双手刀
  七类，每类提供四个等级。

## 使用说明

这些图片是视觉方向与原型用源素材，不是已经逐像素校正的最终
SpriteSheet。需要保留生成细节时使用 `split_original/`，需要统一图标
画布时使用 `split/`。接入正式场景前，应按实际网格尺寸检查缩放、描边
粗细、碰撞范围与相邻图片留白；若缩小到 32 像素，应优先保留轮廓而
不是内部细节。

独立图片由 `tools/split_concept_sheets.py` 生成。工具不会直接沿网格线
机械裁切，而是识别透明设计表中的前景连通块，为每格选定主体轮廓，再
将悬浮宝石、光点和装饰归到空间上最近的主体。这样可以去除跨过网格线
的相邻图片碎片，同时保留属于当前图片的分离部件。

同一设计表中的全部主体先放入相同尺寸的原始分辨率正方形画布，再整体
缩放到 `256×256`，因此等级之间的相对体量不会因逐图放大而丢失。

重新切分并生成 QA 预览：

```bash
/Users/yifanli/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 \
  tools/split_concept_sheets.py \
  --preview-directory tmp/tests/<run>/screenshots
```
