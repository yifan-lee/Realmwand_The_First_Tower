# 开发进度（2026-07-27）

### 更新时间

2026-07-28 20:20 EDT

### 更新内容

- 新增 `EquipmentData`，将装备专属槽位、持手规则和属性加成从 `ItemData` 中分离。
- 新增玩家八槽 `EquipmentManager`：头、胸、手、腿、鞋、左手、右手、饰品。
- 支持仅左手、仅右手、任意手和双手装备规则。
- 支持双持、双手武器占用两槽、单双手互相替换、重复选择卸下装备。
- 战斗背包和普通菜单接入左右手选择、装备差值预览和装备状态标记。
- 普通菜单新增八槽装备总览面板。
- 装备物品时从 `Player.inventory` 移除；被替换或主动卸下的装备重新放回背包。
- 双手装备替换只返还一个物品实例，双持同款替换会分别返还两件。
- 修复普通菜单装备槽物品名列被压缩为 1 像素、导致已装备武器不可见的问题。
