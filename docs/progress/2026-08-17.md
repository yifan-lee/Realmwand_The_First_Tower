### 更新内容

- 完成了全局属性面板（`ActorStatsPanel`）与 Stat UI 体系的架构重构：
  - **统一数据工厂（`ActorStatsFactory`）**：集中读取 `Player`、`Enemy`（含 `Boss`）的名称、头像、描述、等级经验、HP/MP/FP、ATK/DEF/SPD、FP 恢复速度、Start FP、CP 等核心数据；自动合并 `ActorStatsContext`（战斗有效属性、Buff、ATB）与 `ActorStatsPreviewData`（预览预期差值），保持 Actor 与 Resource 实例的纯净性（零修改共享数据）。
  - **强类型配置与上下文（`ActorStatsDisplayProfile` / `ActorStatsContext` / `ActorStatsPreviewData`）**：
    - `ActorStatsDisplayProfile` 提供 `hud()`、`menu()`、`battle_player()`、`battle_enemy()`、`progression()` 预设，精细控制 FP 模式（条/恢复速度）、ATB 模式（隐藏/条/外部）、等级经验、Buff、CP 及 `FeatureUnlocks` 遵守规则。
    - `ActorStatsContext` 提供运行时战斗属性与状态覆盖。
    - `ActorStatsPreviewData` 强类型承载正负预期差值与闪烁效果。
  - **响应式面板组件（`ActorStatsPanel`）**：
    - 公开接口升级为 `bind_actor()`、`set_context()`、`set_preview()`、`clear_preview()`、`refresh()`、`unbind_actor()`。
    - 自动接入 `actor.stats_changed` 信号并在数值变化时自动重绘；更换 Actor 或节点退出树（`_exit_tree`）时安全断开信号。
    - 通过 Godot MCP Pro 为 `actor_stats_panel.tscn` 增补了内置 `AtbRow`（含 `AtbBar` 与 `AtbPreviewSegment`）与 `CpLabel`。
  - **全面迁移消费端 UI**：
    - HUD（`game_stats_column.gd`）接入 `bind_actor(player, hud())`。
    - ESC 菜单（`esc_menu.gd`）接入 `bind_actor(player, menu())`，装备/技能/消耗品悬浮使用 `ActorStatsPreviewData`。
    - 战斗界面（`battle_ui.gd`）分别对 Player 和 Enemy 接入 `bind_actor()`，使用 `ActorStatsContext` 传递 Buff/ATB/有效属性，使用 `ActorStatsPreviewData` 承载 `BattleCalculator` 预览差值，移除旧的每帧轮询。
    - 升级加点界面（`level_up_ui.gd`）接入 `bind_actor(player, progression())`，点数分配变动直接更新 PreviewData。
    - NPC 互动界面（`npc_interaction_ui.gd`）接入 `bind_actor(player, menu())`，强化预览使用 PreviewData。
  - **清理废弃组件与旧入口**：
    - 删除了冗余的 `scenes/ui/components/player_stat_hud.tscn`、`scripts/ui/components/player_stat_hud.gd` 及其 `.uid` 文件。
    - 删除了所有 `_build_player_view()`、`_build_enemy_view()`、`_build_stats_view()` 以及 `ActorStatsViewData.from_player()`。

### 更新时间

2026-08-17

### 更新内容

- 完成了 `ActionEffectData` 与 `StatusEffectData` 的状态管理解耦与系统重构：
  - **状态数据定义（`StatusEffectData` Resource）**：
    - 4 大模块变量：
      1. 效果：`affected_stat`（ATK/DEF/SPD/SKILL_POWER/MAX_HP/MAX_MP）、`operation`（ADD/MULTIPLY）、`value`、`restrict_skill_type` 与 `target_skill_type`；
      2. 结束条件：`end_condition`（PERMANENT/OWNER_ACTIONS/SHIELD_DEPLETED/TRIGGER_COUNT）、`duration_count`（为 0 表示常驻永久）、`trigger_type`（ON_ANY_ACTION/ON_PHYSICAL_ATTACK/ON_MAGICAL_ATTACK）；
      3. 显示定义：`display_name`、`display_template`（支持 `{name}`, `{stat_name}`, `{value}`, `{pct}`, `{remaining}`, `{owner_actions}`, `{stacks}` 动态插值）、`icon`；
      4. 极性与策略：`polarity`（BUFF/DEBUFF/NEUTRAL）、`stack_policy`（REFRESH/ADD_STACK/EXTEND/INDEPENDENT/REPLACE）、`max_stacks`。
  - **运行时状态实例（`ActiveStatus` RefCounted）**：
    - 持有状态数据、剩余行动/触发次数、当前层数；
    - 封装 `is_permanent()`、`is_expired()`、`decrement_trigger()`、`decrement_owner_action()`、`get_formatted_text()` 等高频流转操作。
  - **即时动作效果重构（`ActionEffectData` Resource）**：
    - 纯粹即时效果：`target`（SELF/OPPONENT/ALL）、`resource_type`（HP/MP/FP/SHIELD/NONE）、`calc_method`（FIXED_AMOUNT/SKILL_POWER/MAX_RATIO）、`value`、`is_interrupt` 打断标记、`status_to_apply`（施加的状态 Resource）。
  - **单一真值源状态管理器（`BattleStatusController`）**：
    - 统一保存并流转战斗内所有 Actor 的 `ActiveStatus`；
    - 提供属性加成计算 `get_effective_stat()`、技能威力加成 `get_skill_power_modifier()`、状态生命周期钩子（`on_action_finished()`、`on_trigger_event()`、`on_shield_depleted()`）以及供 UI 读取的格式化字典生成。
  - **战斗系统与计算器重构（`BattleManager` / `BattleCalculator` / `GameFormulas`）**：
    - `BattleManager` 开局根据被动技能为 Actor 注册常驻 `ActiveStatus`，行动结束与破盾时驱动 Controller 结算过期；战后统一清理；
    - `BattleCalculator` 与 `GameFormulas` 完全对接 Controller，废弃无类型字典与旧 Effect 结构。
  - **UI 极性色彩与消费端适配**：
    - `ActorStatsPanel` 支持 Buff（绿色 `#55EFC4`）、Debuff（红色 `#FF7675`）、Neutral（浅灰 `#DFE6E9`）极性颜色渲染；
    - 全量更新 `resources/skills/*.tres` 与 `resources/items/*.tres` 资源。
    - 清理了全部废弃的旧属性（`effect_type`、`operation_type`、`duration` 等）。
